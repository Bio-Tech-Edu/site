# Textos "About" prontos para os repositórios

| Repositório | Texto pronto para o campo "About" |
|:---|:---|
| `chemical-royale` | Arena gamificada de química: átomos, tabela periódica, ligações químicas e desafios de aprendizagem para estudantes do Ensino Médio. |
| `chemical-royale-v2` | Continuação da experiência gamificada em química, com foco em cálculos químicos, radioatividade e aprofundamento de conceitos. |
| `pre-enem-quimica` | Recurso de revisão para o ENEM com questões, desafios e conteúdos de química organizados em trilha de estudo. |
| `solucoes` | Laboratório virtual de soluções, com foco em concentração, diluição, propriedades e experimentação em química. |
| `termoquimica` | Material de apoio em termoquímica com calorimetria, entalpia e aplicações práticas de energia e reação. |
| `cinetica` | Conteúdo sobre cinética química, colisões, mecanismos e catálise para compreender a velocidade das reações. |
| `equilibrio` | Recurso didático sobre equilíbrio químico, Le Chatelier e interpretação de sistemas em equilíbrio. |
| `eletroquimica` | Materiais sobre pilhas, eletrólise, corrosão, faraday e fenômenos de transferência de elétrons. |
| `org` | Química orgânica com foco em estruturas, nomenclatura, reações e estratégias de estudo para o Ensino Médio. |
| `enem` | Recurso de revisão do ENEM com painéis, checklists e apoio à preparação para os dias da prova. |
