# Prompt S6

## P6.1 — Revisar a qualidade do produto

Faça a revisão final do portal em foco na qualidade e consistência geral. Confirme que o documento, os arquivos, os elementos visuais, os dados e os fluxos foram implementados conforme o projeto executivo.

## P6.2 — Validar scripts e CI

Use a automação e os scripts de verificação disponíveis no repositório para confirmar que não há erros de catálogo, HTML, CSS ou processo de integração. Corrija problemas antes do lançamento.

## P6.3 — Preparar lançamento

Organize a checklist final de lançamento, incluindo revisão do conteúdo, URLs, assets, links, licenças e pontos de manutenção. Garanta que os itens essenciais do Anexo B estejam concluídos.

## P6.4 — Documentar pendências e fechamento

Registre as pendências remanescentes e o estado final do portal. Finalize o sprint com uma documentação clara dos pontos concluídos, dos itens críticos e das próximas ações de manutenção.
